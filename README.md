## 💻 Sobre o Projeto

O **ONG Animais em Necessidade** é um website institucional fictício desenvolvido como projeto acadêmico de Front-end.

A proposta do projeto é apresentar uma organização voltada à proteção animal e disponibilizar informações relevantes para visitantes, como projetos realizados, formas de contato, oportunidades de voluntariado e orientações sobre cuidados com animais.

O projeto teve como foco principal a construção da **estrutura e identidade visual de um website**, utilizando HTML5 e CSS3.

---

## 🎯 Objetivos

O website foi planejado para:

* Apresentar informações sobre a ONG;
* Divulgar projetos e iniciativas;
* Facilitar o contato com voluntários;
* Disponibilizar um canal para denúncias;
* Permitir o cadastro de interessados em realizar trabalho voluntário;
* Compartilhar dicas e informações sobre cuidados com animais.
